# Journal des modifications

Le format suit les principes de Keep a Changelog.

## 1.0.0 (2026-11-03)

### Ajouté

- `Get-CopilotAppAdoptionReport` : lecture seule du rapport d'utilisation de Microsoft Copilot par utilisateur sur 30 jours via le point d'accès bêta de Microsoft Graph.
- `Get-CopilotAppAdoptionSummary` : résumé du nombre d'utilisateurs ayant une activité renseignée dans Word, Excel et PowerPoint.
- `Export-CopilotAppAdoptionReport` : écriture d'un rapport HTML simple, protégée par SupportsShouldProcess et compatible avec -WhatIf.
